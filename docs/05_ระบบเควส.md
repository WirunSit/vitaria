# 05 · ระบบเควส (Quest System) — ฉบับพื้นฐาน v1

> เป้าหมาย v1: ระบบเรียบง่าย ทำงานได้จริง ขับเคลื่อนด้วย Data (JSON) เพิ่มเควสใหม่ได้โดยไม่แก้โค้ด
> ระบบขั้นสูง (เควสแตกแขนง, ตัวเลือกส่งผลระยะยาว, เควสสุ่ม) จะเพิ่มในเวอร์ชันถัดไป

## 2. โครงสร้างข้อมูลเควส (ลำดับชั้น)

```
Quest (เควส)
 ├── ข้อมูลทั่วไป: id, ชื่อ, ประเภท, คำอธิบาย, เงื่อนไขปลดล็อก, รางวัล, หัวข้อชีววิทยา
 └── Steps[] (ขั้นตอน — ทำทีละขั้นตามลำดับ)
       ├── คำอธิบายขั้นตอน (แสดงใน Quest Log)
       ├── Objectives[] (เป้าหมาย — ในขั้นเดียวกันทำพร้อมกันได้ ต้องครบทุกข้อ)
       └── onComplete: เหตุการณ์เมื่อจบขั้น (เล่นบทสนทนา, ให้ไอเทม, เปิดพื้นที่)
```

### 2.1 สถานะเควส (Quest State)

```
 LOCKED ──(เงื่อนไขผ่าน)──► AVAILABLE ──(รับเควส/เริ่มอัตโนมัติ)──► ACTIVE ──(ทำครบทุก Step)──► COMPLETED
                                                                    │
                                                                    └──(ยกเลิก — เฉพาะ World)──► AVAILABLE
```

| สถานะ | ความหมาย | การแสดงผล |
|------|---------|----------|
| LOCKED | ยังไม่ผ่านเงื่อนไข | ไม่แสดง |
| AVAILABLE | รับได้ | ไอคอน "!" เหนือหัว NPC + บนแผนที่ |
| ACTIVE | กำลังทำ | แสดงใน Quest Log, ติดตามได้ |
| COMPLETED | เสร็จแล้ว | ย้ายไปแท็บ "เสร็จสิ้น" (อ่านบทสนทนาย้อนหลังได้) |

> v1 ไม่มีสถานะ FAILED — เควสทั้งหมดทำซ้ำขั้นตอนได้เรื่อย ๆ จนสำเร็จ (ลดความหงุดหงิดของผู้เรียน)

### 2.2 ประเภท Objective (v1 มี 9 แบบ)

| Type | ความหมาย | พารามิเตอร์ | ตัวอย่าง |
|-----|---------|-----------|--------|
| `TALK` | คุยกับ NPC | `npcId`, `dialogueId` | คุยกับศาสตราจารย์ไลโซ |
| `GOTO` | ไปยังตำแหน่ง | `locationId`, `radius` | ไปที่ทะเลสาบเยื่อหุ้ม |
| `COLLECT` | เก็บไอเทม | `itemId`, `count` | เก็บเห็ดเรืองแสง ×5 |
| `DEFEAT` | กำจัดศัตรู | `enemyId` หรือ `enemyTag`, `count` | กำจัดแบคทีเรีย ×6 |
| `SCAN` | สแกนสิ่งต่าง ๆ ด้วย Bio-Scanner | `targetId` หรือ `targetTag`, `count` | สแกนออร์แกเนลล์ 3 ชนิด |
| `QUIZ` | ตอบคำถาม | `quizSetId`, `passScore` | ตอบถูก 3/5 ข้อ |
| `PUZZLE` | แก้ปริศนา | `puzzleId` | เปิดประตูเอนไซม์ |
| `DELIVER` | ส่งไอเทมให้ NPC | `npcId`, `itemId`, `count` | ส่งตัวอย่างให้ป้ากอลจี |
| `INTERACT` | กดโต้ตอบวัตถุ | `objectId` | เปิดกล้องจุลทรรศน์ยักษ์ |

**ส่วนขยายในอนาคต**: `ESCORT`, `TIMED`, `USE_ITEM`, `REACTION` (ทำปฏิกิริยาธาตุที่กำหนด), `PARTY_HAS` (มีตัวละคร X ในทีม)

### 2.3 เงื่อนไขปลดล็อก (Prerequisites)
| Type | ตัวอย่าง |
|-----|--------|
| `QUEST_COMPLETED` | ต้องจบเควส `MQ_P_03` |
| `RR_AT_LEAST` | Research Rank ≥ 10 |
| `HAS_CHARACTER` | มีไมโทร่า |
| `MASTERY_AT_LEAST` | Mastery หัวข้อ `bio.cell.organelle` ≥ ★1 |
| `TIME_OF_DAY` | 18:00–06:00 |
| `TEACHER_UNLOCK` | ครูเปิดให้ (ผ่าน Dashboard) |

## 4. การทำงานของระบบ (Runtime Logic)

```
QuestManager
 ├── โหลด Quest Data ทั้งหมดตอนเริ่มเกม
 ├── ตรวจ prerequisites ทุกครั้งที่มี GameEvent (จบเควส, RR ขึ้น, ได้ตัวละคร) → LOCKED → AVAILABLE
 ├── รับ GameEvent จาก EventBus:
 │     EnemyDefeated(enemyId, tags) / ItemCollected(itemId, n) / TalkedTo(npcId)
 │     EnteredArea(locationId) / Scanned(targetId, tags) / QuizPassed(quizSetId, score)
 │     PuzzleSolved(puzzleId) / Interacted(objectId)
 ├── อัปเดต progress ของ Objective ใน Step ปัจจุบัน
 ├── ทุก Objective ครบ → รัน onComplete → Step ถัดไป
 └── ทุก Step ครบ → ให้ rewards → COMPLETED → START nextQuest (ถ้ามี)
```

### 4.1 การบันทึก (Save)
```json
"questProgress": {
  "MQ_P_01": { "state": "COMPLETED" },
  "MQ_P_02": { "state": "ACTIVE", "stepIndex": 1, "objectiveProgress": [2, 0] },
  "WQ_C_01": { "state": "AVAILABLE" }
},
"trackedQuestId": "MQ_P_02",
"flags": { "met_mitora": true }
```

### 4.2 การติดตาม (Tracking)
- ติดตามได้ทีละ 1 เควส
- แสดงบน HUD (มุมซ้ายบน): ชื่อเควส + Objective ปัจจุบัน + ระยะทาง (เมตร)
- มาร์กเกอร์บนจอและแผนที่: วงกลมพื้นที่ (กรณี `GOTO`/`COLLECT`/`DEFEAT`), ลูกศรชี้ NPC
- เควสหลักติดตามอัตโนมัติเมื่อรับ

## 5. ตัวอย่างเนื้อหา: บทนำ (Prologue) — "ผู้ค้นหาแห่งเซลล์"

ระยะเวลาเล่น ~45–60 นาที | หัวข้อ: การศึกษาชีววิทยา + ปูพื้นเรื่องเซลล์

| ID | ชื่อเควส | ขั้นตอนหลัก | หัวข้อที่สอน | ปลดล็อก |
|----|--------|-----------|------------|--------|
| **MQ_P_01** | ตื่นขึ้นในหุบเซลล์ | ตื่นขึ้น → ไปที่คริสตัล → พบอะมีบี้ถูกแบคทีเรียล้อม → สู้ครั้งแรก (สอนโจมตี/หลบ) → สแกนซาก | แบคทีเรียคืออะไร (การ์ดพื้นฐาน) | Bio-Scanner |
| **MQ_P_02** | แกนชีวิตที่ว่างเปล่า | อะมีบี้พาไปรูปปั้นต้นไม้แห่งชีวิต → แตะรูปปั้น → แกนชีวิตเรียนรู้ Geo → สอนสกิล E/Q บนหุ่นฝึก → เปิดแผนที่ | ทฤษฎีเซลล์ 3 ข้อ (ผ่านบทพูดของรูปปั้น) | ธาตุ Geo, แผนที่, Waypoint |
| **MQ_P_03** | ปริศนาของนักวิทยาศาสตร์ | พบประตูหินปิด → แก้ปริศนา "วิธีการทางวิทยาศาสตร์" (สังเกตพืชเหี่ยว → ตั้งสมมติฐาน → ทดลองรดน้ำ/ให้แสง → สรุป) | วิธีการทางวิทยาศาสตร์, ตัวแปรต้น/ตาม/ควบคุม | Puzzle tutorial |

| **MQ_P_06** | ประตูสู่เซลลาเรีย | เดินทางไปนครเซลลาเรีย → บอสมินิ "แบคทีเรียราชา" (Knowledge Shield ครั้งแรก — ถาม 1 ข้อ) → เข้าเมือง → พบศาสตราจารย์ไลโซ → **Quiz ปิดบท (5 ข้อ ผ่าน 3)** "การสอบเข้าสถาบัน" | ทบทวนทั้งบท | นครเซลลาเรีย, ร้านค้า, จบบทนำ → เปิดบทที่ 1 |

## 6. บทที่ 1 (โครงร่าง) — "เซลล์ที่ไม่ยอมหยุดแบ่งตัว"

| ตอน | ชื่อ | เนื้อเรื่องย่อ | หัวข้อ |
|-----|-----|--------------|------|
| 1-1 | นักเรียนใหม่แห่งสถาบัน | ปฐมนิเทศ ทัวร์ย่านต่าง ๆ ของเมือง (= ออร์แกเนลล์) ภารกิจสแกนออร์แกเนลล์ 10 ชนิด | โครงสร้างเซลล์, ออร์แกเนลล์ |
| 1-2 | โมเลกุลที่หายไป | ร้านอาหารขาดวัตถุดิบ ต้องเดินทางไปที่ราบโมเลกุล รวบรวม "โมเลกุลพื้นฐาน" พบ **คลอเรน** | สารชีวโมเลกุล |
| 1-3 | ป่าที่เอนไซม์ไม่ทำงาน | ประตูเอนไซม์ทั้งป่าหยุดทำงานเพราะอุณหภูมิผิดปกติ (ซินดิเคตติดตั้งเครื่องทำความร้อน) | เอนไซม์ |
