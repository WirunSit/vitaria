# 06 · ศัตรูและบอส (Enemies & Bosses)

## 0. หลักการออกแบบศัตรู
1. **ทุกศัตรูมีต้นแบบจริง** (จุลชีพ เชื้อโรค หรือกระบวนการทางชีววิทยาที่ผิดปกติ) และมีการ์ด Bio-Pedia
2. **พฤติกรรมสะท้อนความจริง** เช่น ไวรัสต้อง "เกาะ" เป้าหมายจึงเพิ่มจำนวน, แบคทีเรียแบ่งตัวถ้าไม่จัดการเร็ว
3. **หน้าตาน่ารัก-น่าเกรงขาม** ไม่สยดสยอง (เรต 12+) — สไตล์สไลม์/มอนสเตอร์อนิเมะ
4. **ห้ามสื่อว่า "จุลชีพทุกชนิดเป็นสิ่งเลวร้าย"** — มีจุลชีพที่เป็นมิตร (NPC แบคทีเรียโพรไบโอติก) เพื่อความถูกต้อง

### 1.1 ⭐ กลไก "การแบ่งตัวแบบทวีคูณ (Binary Fission)"
- แบคทีเรียสไลม์ทุกตัวมีตัวนับเวลา **20 วินาที** — ถ้ายังไม่ตาย จะแบ่งเป็น 2 ตัว (HP ตัวละ 60% ของตัวเดิม)
- สูงสุด 3 รุ่น (1 → 2 → 4 → 8) ป้องกันการบานปลาย
- **สอน**: การเพิ่มจำนวนแบบทวีคูณ (Exponential Growth), Binary Fission
- เมื่อแบ่งตัวครั้งแรก อะมีบี้พูด: "เฮ้ย! มันแบ่งตัวแบบ Binary Fission! รีบจัดการก่อนมันเพิ่มเป็นทวีคูณ!"

### 1.2 ⭐ กลไก "ไวรัสต้องอาศัยเซลล์โฮสต์"
- เฟจโดรนเพิ่มจำนวนเองไม่ได้ — มันต้องเกาะแบคทีเรียสไลม์แล้ว 5 วิ ต่อมา สไลม์ระเบิดปล่อยเฟจใหม่ 3 ตัว (Lytic Cycle)
- ผู้เล่นใช้ประโยชน์ได้: ปล่อยให้เฟจกำจัดแบคทีเรียให้ แล้วค่อยจัดการเฟจ (แนวคิด Phage Therapy)
- **ยาปฏิชีวนะไม่มีผลกับไวรัส** — ถ้าผู้เล่นปา Antibiotic Flask ใส่เฟจ จะขึ้นข้อความ "ไม่มีผล! ไวรัสไม่มีผนังเซลล์หรือกลไกที่ยาปฏิชีวนะออกฤทธิ์" + ปลด Achievement ลับ

### 1.3 ⭐ กลไก "เชื้อดื้อยา (Antibiotic Resistance)"
```
ถ้าผู้เล่นใช้ Antibiotic Flask ในโซนเดียวกัน ≥ 5 ครั้ง ภายใน 1 วันในเกม
  → แบคทีเรียที่เกิดใหม่ในโซนนั้นมีโอกาส 30% เป็น "สายพันธุ์ดื้อยา" (ขอบสีแดง, ไอคอนโล่ยา)
  → สายพันธุ์ดื้อยา: ไม่รับดาเมจจากยาปฏิชีวนะ, HP +50%
  → หายไปเมื่อผู้เล่นไม่ใช้ยาในโซนนั้น 3 วันในเกม
```
- **สอน**: การคัดเลือกโดยธรรมชาติ, การใช้ยาปฏิชีวนะอย่างสมเหตุผล
- มีเควสโลกอธิบายเรื่องนี้ (WQ ในบทที่ 6 อควอร์รา) แต่กลไกทำงานตั้งแต่ MVP

## 3. บอสโลก (World Bosses) — MVP

| หัวข้อ | รายละเอียด |
|-------|-----------|
| ต้นแบบ | เซลล์มะเร็ง — การแบ่งเซลล์ที่ไม่ถูกควบคุม (วัฏจักรเซลล์ผิดปกติ) |
| ตำแหน่ง | ยอดหอคอยไมโทซิส |
| รูปลักษณ์ | ยักษ์หินผลึกขนาดใหญ่ที่ประกอบจากก้อนเซลล์หกเหลี่ยมซ้อนกันอย่างไม่เป็นระเบียบ บางส่วนมีก้อนเนื้อผลึกงอกออกมาเรื่อย ๆ สีม่วงเข้มปนทอง แกนกลางเรืองแสงสีแดง |
| HP (Lv50) | ~350,000 |
| **ระยะที่ 1** | ทุบพื้น ขว้างก้อนผลึก / ทุก 30 วิ สร้าง "ก้อนเนื้องอก" 3 ก้อนรอบตัว (ถ้าไม่ทำลายใน 15 วิ บอสฟื้น HP 10%) |
| **Knowledge Shield 1** (HP 70%) | "จุดตรวจสอบ (Checkpoint) ในวัฏจักรเซลล์มีหน้าที่อะไร?" |
| **ระยะที่ 2** | **แพร่กระจาย (Metastasis)**: ส่งเศษผลึกไปฝังพื้นทั่วสนาม ระเบิดตามเวลา |
| **Knowledge Shield 2** (HP 35%) | คำถามเรื่องเปรียบเทียบไมโทซิส/ไมโอซิส |
| **ระยะที่ 3** | เร็วขึ้น ก้อนเนื้องอกงอกบ่อยขึ้น |
| จุดอ่อน | Denaturation, Lysis; ตีแกนแดงที่หลังขณะบอสล้ม |
| ดรอป | แกนโกเลมมะเร็ง, อัญมณีแคลไซต์, Relic |
| ⚠️ ความละเอียดอ่อน | เนื้อหาเรื่องมะเร็งเขียนอย่างระมัดระวัง ให้ข้อมูลที่ถูกต้องและมีความหวัง (เน้นการตรวจคัดกรอง/การรักษา) ไม่สร้างความกลัว |
