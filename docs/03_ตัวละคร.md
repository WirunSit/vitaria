# 03 · ตัวละคร (Characters)

## 0. ภาพรวม

### 0.1 ฉากของตัวละครชุดแรก
ตัวละครชุดแรกทั้งหมดเป็น **นักเรียน/อาจารย์ของ "สถาบันเซลลาเรีย (Cellaria Academy)"** ในนครเซลลาเรีย (ดินแดนไซโทเรีย)
ซึ่งเป็นสถาบันนานาชาติที่รับนักเรียนจากทั้ง 7 ดินแดน → ทำให้ MVP มีตัวละครครบ 7 ธาตุได้ตั้งแต่ดินแดนแรก และผู้เล่น (นักเรียนจริง) รู้สึกใกล้ตัว

- **ไซร่า**: เด็กสาวผมสีขาวมุกยาวมัดครึ่งหัว ปลายผมไล่สีตามธาตุ ดวงตาสีทอง ชุดเดรสสั้นสีขาว-กรมท่า ลายหกเหลี่ยม เสื้อคลุมไหล่ บู๊ตสูง แกนชีวิตที่ข้อมือขวา
