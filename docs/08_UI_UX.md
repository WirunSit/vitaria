## 2. HUD ขณะเล่น (Exploration / Combat)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [มินิแมป]   🟡 เควสติดตาม: ปริศนาของนักวิทยาศาสตร์       [⚙][📖][🎁][✉] [ไอคอนเมนู] │
│  (วงกลม)    ▸ ทำการทดลอง (0/1)  · 42 ม.                                         │
│                                                              ┌──────────────┐ │
│                                                              │1 [หน้า] ไมโทร่า │ │
│                                                              │2 [หน้า] อัลวี  │ │
│                    [ เป้าหมาย / ตัวละคร ]                    │3 [หน้า] คลอเรน │ │
│                                                              │4 [หน้า] ผู้เล่น│ │
│                                                              └──────────────┘ │
│ [อะมีบี้ ฟองคำพูด: "ใช้ Pyro ละลายเมือกนั่นสิ!"]                                │
│                                                                                │
│        ████████████░░░░  HP 12,450 / 15,000   Lv.40                [E ⏱] [Q ⚡] │
│                                                          [T สแกน] [🧪ยา]       │
└──────────────────────────────────────────────────────────────────────────────┘
```
- **ศัตรู**: แถบ HP เหนือหัว + ไอคอนธาตุที่เคลือบ + ระดับเลเวล; บอสแสดงแถบ HP ใหญ่ด้านบน + ชื่อ + ฉายา
- **Knowledge Shield**: เมื่อเปิด เวลาหยุด ฉากหลังเบลอ หน้าต่างคำถามกลางจอ ขอบเรืองแสงสีบอส
- **ตัวเลขดาเมจ**: สีตามธาตุ; ปฏิกิริยาแสดงชื่อปฏิกิริยาภาษาไทยตัวใหญ่ (เช่น "เสียสภาพ!") ครั้งแรกมีไอคอน 📖 กระพริบ (มีการ์ดใหม่)

## 4. รายละเอียดหน้าจอสำคัญ

### 4.1 หน้าตัวละคร
```
┌─────────────────────────────────────────────────────────────────────┐
│ [แท็บซ้าย]                     [ภาพตัวละครเต็มตัว 3D หมุนได้]     [ข้อมูลขวา] │
│  ▸ ค่าสถานะ                                                        ไมโทร่า ★★★★ │
│  ▸ อาวุธ                                                           🔥 Pyro      │
│  ▸ Bio-Relic                                                       Lv. 40/50    │
│  ▸ ลำดับยีน (C1–C6)                                                HP  8,240    │
│  ▸ ทาเลนต์                                                         ATK 1,120    │
│  ▸ ประวัติ / เสียงพูด                                              DEF   480    │
│  ▸ 🧬 ความรู้ (หัวข้อที่ตัวละครนี้สอน + Mastery)                    BM     60    │
│                                                                    [เลื่อนขั้น]  │
└─────────────────────────────────────────────────────────────────────┘
```
- แท็บ **"ความรู้"** (ใหม่ — ไม่มีในเกมต้นแบบ): แสดงหัวข้อชีววิทยาของตัวละคร, Mastery, ปุ่มไปเควสตัวละคร, ปุ่ม "ทดสอบ"
- หน้า Gene Sequence: วาดเป็น **เกลียว DNA หมุน** มี 6 จุด (แทนกลุ่มดาว)

### 4.2 หน้า Gene Wish
- พื้นหลัง: ภาพแบนเนอร์ตัวละครเด่น (Splash Art)
- ปุ่ม: สุ่ม 1 ครั้ง / สุ่ม 10 ครั้ง / รายละเอียด / ประวัติ / **"ทำไมถึงเป็นอัตรานี้?"**
- ตัวนับ pity แสดงชัดเจนเสมอ ("อีก 23 ครั้งการันตี ★5") — โปร่งใส
- แอนิเมชันสุ่ม: เกลียว DNA หมุนเร็วขึ้น → แตกเป็นแสง สีบอกระดับ (ฟ้า ★3 / ม่วง ★4 / ทอง ★5)

### 4.3 หน้า Bio-Pedia
```
┌──────────────────────────────────────────────────────────────┐
│ [หมวด] สิ่งมีชีวิต | ศัตรู | ปฏิกิริยา | แนวคิด | นักวิทยาศาสตร์ | ศัพท์ │
│ ─────────────────────────────────────────────────────────────── │
│ [กริดการ์ด 4×3]  (การ์ดที่ยังไม่ปลด = เงาดำ + "???")           │

│                    Mastery ★★☆ | [ทดสอบ 3 ข้อ] [ดูในแผนที่]     │

└──────────────────────────────────────────────────────────────┘
```

### 4.4 หน้า Quiz
**แบบบทสนทนา** (ในเควส): กล่องบทสนทนาด้านล่าง ตัวละครถามพร้อมสีหน้า ตัวเลือกเป็นปุ่มด้านขวา (เหมือนตัวเลือกบทสนทนา) → รู้สึกเป็นส่วนหนึ่งของเรื่อง

**แบบเต็มจอ** (Quiz ปิดบท / Daily Review):
```
┌──────────────────────────────────────────────────────────┐
│  ข้อ 3/5        #เซลล์ > การลำเลียงสาร      ⏱ ไม่จำกัดเวลา  │
│                                                            │
│  "นำเซลล์เม็ดเลือดแดงใส่ในน้ำกลั่น จะเกิดอะไรขึ้น?"        │
│              [ภาพประกอบ (ถ้ามี)]                           │
│                                                            │
│  [ A  เซลล์เหี่ยว ]        [ B  เซลล์เต่งและแตก ]           │
│  [ C  ไม่เปลี่ยนแปลง ]     [ D  เซลล์แบ่งตัว ]              │
│                                                            │
│  [💡 ถามอะมีบี้ (คำใบ้ 3)]                    [ยืนยันคำตอบ] │
└──────────────────────────────────────────────────────────┘
```
- หลังตอบ: ✅/❌ + เอฟเฟกต์ + **คำอธิบายเสมอ** + ปุ่ม "เปิดการ์ด Bio-Pedia"
- Quiz เพื่อการเรียนรู้ **ไม่จับเวลา** (ยกเว้น Classroom Mode ที่ครูเปิด)

### 4.5 หน้ารายงานความก้าวหน้า (นักเรียนดูเอง)
- กราฟใยแมงมุม (Radar) Mastery ตามหมวด, หัวข้อที่ควรทบทวน 3 อันดับ, สถิติ (ตอบถูก %, การ์ดสะสม, วันเล่นต่อเนื่อง)

### 4.6 แผนที่
- ไอคอน: Synapse Node, รูปปั้นต้นไม้, โดเมน, บอส, เควส (สีตามประเภท), ร้านค้า, หีบที่พบ
- เลเยอร์ "หัวข้อการเรียน": ระบายสีโซนตาม Mastery (แดง → เขียว) ⭐

## 6. Flow ผู้ใช้ครั้งแรก (FTUE — First Time User Experience)
```
Title → เลือกภาษา → (ถ้ามี) กรอกรหัสห้องเรียน / ข้าม → คัตซีนเปิด (ฝาแฝดถูกลักพาตัว 60 วิ)
 → เลือกเพศนักเดินทาง + ตั้งชื่อ → ตื่นในหุบเซลล์ (MQ_P_01)
 → สอนเดิน/กล้อง → พบอะมีบี้ → สอนต่อสู้ → สอนสแกน → รูปปั้น (สอน E/Q) → ...
 → จบบทนำ (~45–60 นาที) → เปิด Gene Wish ตู้มือใหม่ + ของขวัญต้อนรับ
```
- **เป้า**: ภายใน 10 นาทีแรก ผู้เล่นต้องได้ต่อสู้, ได้สแกน, ได้การ์ดความรู้ใบแรก, ได้ตอบคำถามถูก 1 ข้อ

## 7. เสียงและการตอบสนอง (Feedback)
| เหตุการณ์ | เสียง / เอฟเฟกต์ |
|----------|---------------|
| ตอบถูก | เสียงระฆังใส + อนุภาคทองพุ่ง + ข้อความ "ยอดเยี่ยม!" |
| ตอบผิด | เสียงต่ำนุ่ม (ไม่ดุ) + อะมีบี้: "ไม่เป็นไร มาดูกันว่าทำไม!" |
| ปลดการ์ดใหม่ | เสียงเปิดหนังสือ + การ์ดหมุนบินเข้าไอคอน 📖 |
| Mastery ขึ้นดาว | แฟนแฟร์สั้น + ป๊อปอัปเล็กมุมขวา |
| ปฏิกิริยาธาตุ | เสียงเฉพาะแต่ละปฏิกิริยา |
