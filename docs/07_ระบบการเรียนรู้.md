# 07 · ระบบการเรียนรู้ (Learning Systems)

> หัวใจที่ทำให้เกมนี้ต่างจากเกมทั่วไป — ความรู้ต้อง **ฝังในเกม** และ **วัดผลได้**

## 1. ภาพรวมจุดที่ผู้เล่น "เรียน" และ "ถูกวัดผล"

| จุดสัมผัส | รูปแบบ | ความถี่ | ผลต่อเกม | วัดผล? |
|----------|-------|--------|---------|-------|
| บทสนทนาเควส | อธิบายผ่านตัวละคร/อะมีบี้ | ตลอด | — | ❌ |

## 2. โครงสร้างหัวข้อ (Topic Tree)

ทุกเนื้อหา (คำถาม, การ์ด, เควส) ผูกกับ **Topic ID** แบบลำดับชั้น เพื่อวิเคราะห์จุดอ่อนรายหัวข้อ

```
bio
├── intro                         (การศึกษาชีววิทยา)
│   ├── characteristics_of_life   ลักษณะของสิ่งมีชีวิต
│   ├── science_method            วิธีการทางวิทยาศาสตร์
│   └── microscope                กล้องจุลทรรศน์
├── chem                          (เคมีที่เป็นองค์ประกอบของสิ่งมีชีวิต)
│   ├── water                     น้ำ
│   ├── carbohydrate              คาร์โบไฮเดรต
│   ├── lipid                     ลิพิด
│   ├── protein                   โปรตีน
│   ├── nucleic_acid              กรดนิวคลีอิก
│   └── enzyme                    เอนไซม์และปฏิกิริยาเคมี
├── cell                          (เซลล์และการทำงานของเซลล์)
│   ├── cell_theory               ทฤษฎีเซลล์
│   ├── organelle                 ออร์แกเนลล์
│   ├── prokaryote_eukaryote      โพรคาริโอต / ยูคาริโอต
│   ├── membrane_transport        การลำเลียงผ่านเยื่อหุ้มเซลล์
│   ├── cell_communication        การสื่อสารระหว่างเซลล์
│   ├── cell_division             การแบ่งเซลล์ (Mitosis / Meiosis)
│   ├── cell_cycle                วัฏจักรเซลล์
│   └── cellular_respiration      การหายใจระดับเซลล์
├── genetics ...   (เพิ่มเมื่อเปิดดินแดนเจโนเวีย)
├── evolution ...
├── plant ...
├── animal ...
└── ecology ...
```

## 3. คลังข้อสอบ (Question Bank)

### 3.1 ประเภทคำถาม
| Type | ชื่อ | การแสดงผลในเกม | ระดับ Bloom ที่เหมาะ |
|-----|-----|--------------|-------------------|
| `MCQ` | ปรนัย 4 ตัวเลือก | ปุ่ม 4 ปุ่ม | Remember–Apply |
| `TF` | ถูก/ผิด | 2 ปุ่ม | Remember |
| `MULTI` | เลือกได้หลายข้อ | ช่องติ๊ก | Understand |
| `ORDER` | เรียงลำดับ | ลากเรียง (เช่น ระยะไมโทซิส) | Understand |
| `MATCH` | จับคู่ | ลากเส้นเชื่อม (ออร์แกเนลล์ ↔ หน้าที่) | Remember–Understand |
| `LABEL` | ติดป้ายภาพ | ลากป้ายไปวางบนภาพเซลล์ | Remember |
| `NUMERIC` | ตอบตัวเลข | พิมพ์ตัวเลข (เช่น อัตราส่วน Punnett) | Apply |
| `DATA` | วิเคราะห์กราฟ/ผลการทดลอง | แสดงกราฟ + MCQ | Analyze |

### 3.3 มาตรฐานการเขียนข้อสอบ
- ตัวลวงทุกตัวต้อง **สมเหตุสมผล** และอิงความเข้าใจผิดที่พบบ่อย (บันทึกใน `distractorNotes`)
- ทุกข้อต้องมี `explanation` — แสดงเสมอหลังตอบ ทั้งถูกและผิด
- ห้ามใช้ "ถูกทุกข้อ / ผิดทุกข้อ"
- ความยาวคำถาม ≤ 50 คำ (เกมเล่นบนจอ)
- ระดับความยาก 1–5: 1–2 = Eco Level 0–2, 3 = EL 3–5, 4–5 = EL 6+ และ Quiz ปิดบท
- ผ่านการตรวจโดยครูอย่างน้อย 1 คน (`reviewed_by`) ก่อนนำเข้าเกมจริง

|------|--------|

## 4. ระบบ Mastery (ความเชี่ยวชาญรายหัวข้อ)

แต่ละ Topic (ระดับใบ) มีคะแนน Mastery 0–100 แสดงเป็นดาว:

| ดาว | คะแนน | ความหมาย |
|-----|------|---------|
| ☆☆☆ | 0–29 | เพิ่งรู้จัก |
| ★☆☆ | 30–59 | เข้าใจพื้นฐาน |
| ★★☆ | 60–84 | เข้าใจดี |
| ★★★ | 85–100 | เชี่ยวชาญ |

**การคำนวณ (Elo-like แบบง่าย)**
```
expected = 1 / (1 + 10^((difficulty×20 − mastery) / 40))
ตอบถูก:  mastery += K × (1 − expected)       // K = 12
ตอบผิด:  mastery −= K × expected × 0.6        // ลงช้ากว่าขึ้น เพื่อไม่ให้ท้อ
ใช้คำใบ้: ได้คะแนนครึ่งเดียว
clamp 0..100
```

**การใช้ประโยชน์ในเกม**
- Mastery ★1 → ปลดเควสบางเควส
- Mastery ★3 ทุกหัวข้อในโซน → ได้ "ตราผู้เชี่ยวชาญ" + ชุดตัวละคร/ฉายา
- Teacher Dashboard ใช้ข้อมูลนี้ดูจุดอ่อนของนักเรียน

## 5. Spaced Repetition (ทบทวนแบบเว้นระยะ) — Daily Review

ใช้ระบบ **Leitner Box 5 กล่อง** (เข้าใจง่าย เหมาะกับเกม)

| กล่อง | ทบทวนอีกครั้งใน |
|------|---------------|
| 1 | 1 วัน |
| 2 | 2 วัน |
| 3 | 4 วัน |
| 4 | 8 วัน |
| 5 | 16 วัน (แล้ววนต่อเรื่อย ๆ) |

```
ทุกคำถามที่ผู้เล่นเคยเจอ → เข้ากล่อง 1
ตอบถูกใน Daily Review → เลื่อนขึ้น 1 กล่อง
ตอบผิด → กลับกล่อง 1

การเลือก 5 ข้อต่อวัน:
  1. ข้อที่ "ถึงกำหนด" (dueDate ≤ วันนี้) เรียงตามกล่องต่ำสุดก่อน
  2. ถ้าไม่พอ → เติมด้วยหัวข้อที่ Mastery ต่ำสุด
  3. ไม่เลือกข้อเดิมที่เพิ่งตอบเมื่อวาน (เว้นแต่ผิด)
  4. สุ่มเปลี่ยนลำดับตัวเลือกทุกครั้ง (กันการจำตำแหน่ง)
```

## 6. Adaptive Difficulty (ปรับความยากอัตโนมัติ)
- ข้อสอบที่สุ่มให้ = อิง **Eco Level** + **Mastery หัวข้อนั้น**
- ตอบผิดติดกัน 3 ข้อ → ข้อต่อไปลดความยาก 1 ระดับ + อะมีบี้เสนอ "อ่านการ์ดทบทวนไหม?"
- ตอบถูกติดกัน 5 ข้อ → เพิ่มความยาก + ได้บัฟ "สมองแล่น" (ATK +10% 10 นาที) 🧠

## 7. ระบบคำใบ้ (Hint)
- กด `F1` หรือปุ่ม "ถามอะมีบี้" — มี 3 ระดับ:
  1. ชี้แนวคิด ("นึกถึงหน้าที่ของออร์แกเนลล์")
  2. ตัดตัวเลือกผิด 1 ข้อ
  3. เปิดการ์ด Bio-Pedia ที่เกี่ยวข้อง
- การใช้คำใบ้ไม่ลงโทษในเกม แต่บันทึกใน analytics

## 8. การป้องกันการเดาสุ่ม
- ตอบเร็วผิดปกติ (< 2 วินาที) ซ้ำ ๆ → ไม่ได้ผลึกปัญญาข้อนั้น + อะมีบี้ทักว่า "อ่านคำถามก่อนนะ!"
- ตอบผิดใน Daily Review ไม่เสียอะไร แต่ได้รางวัลตามจำนวนข้อถูก → ไม่จูงใจให้เดา

## 9. Teacher Dashboard (เว็บแยก — เฟส 2)

### 9.1 ฟังก์ชันหลัก
| ฟังก์ชัน | รายละเอียด |
|---------|-----------|
| สร้างห้องเรียน | ได้รหัสห้อง 6 หลัก ให้นักเรียนกรอกในเกม |
| ดูความก้าวหน้า | % ความคืบหน้าเควส, เวลาเล่น, Mastery รายหัวข้อ (Heatmap นักเรียน × หัวข้อ) |

### 9.3 ความเป็นส่วนตัว (สำคัญ — ผู้ใช้เป็นผู้เยาว์)
- เก็บข้อมูลขั้นต่ำ: ชื่อเล่น + รหัสห้อง (ไม่เก็บอีเมล/เบอร์โทรนักเรียน)
- ปฏิบัติตาม **พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA)** — ต้องมีความยินยอมจากผู้ปกครอง/โรงเรียน
- โหมดออฟไลน์เล่นได้ 100% โดยไม่ส่งข้อมูลใด ๆ
