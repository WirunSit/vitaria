## 1. ระบบความก้าวหน้าของผู้เล่น

### 1.1 Research Rank (RR) 1–60 (MVP: 1–25)
EXP ได้จาก: เควส, Daily Research, เปิดหีบ, สแกนสิ่งมีชีวิตใหม่, ใช้พลังงาน ATP, **ตอบ Quiz ถูก**

| RR | ปลดล็อก |
|----|--------|
| 1 | เริ่มเกม |
| 5 | ระบบ Bio-Relic |
| 10 | Gene Wish, Lab Synthesis |
| 12 | Daily Research, Lab Domain (ตำราทาเลนต์) |
| 16 | Co-op (อนาคต), Expedition |
| 20 | Eco Level 1, Evolution Tower (อนาคต) |
| 25 | Eco Level 2, Weekly Boss |
| 30/35/40/45/50 | Eco Level 3–7 |

### 1.2 Eco Level (World Level) 0–8
- ศัตรูเลเวลสูงขึ้น ดรอปดีขึ้น คำถามใน Quiz **ยากขึ้น** (เลื่อนระดับ Bloom)
- ลดระดับได้ 1 ขั้น (คูลดาวน์ 24 ชม.)

## 2. ระบบตัวละคร (Character Progression)

### 2.1 เลเวล
| ไอเทม EXP | ชื่อในเกม | EXP |
|----------|----------|-----|
| เล็ก | น้ำตาลโมเลกุลเดี่ยว (Monosaccharide) | 1,000 |

### 2.3 Talent
- Lv 1–10 (ต้องเลื่อนขั้นตามเกณฑ์: Lv 2 ต้อง A1, Lv 7+ ต้อง A6)
- ใช้ตำราความรู้ 3 ระดับ + ดรอปศัตรู + กลูโคส + Lv 7+ ต้องใช้วัตถุดิบบอสประจำสัปดาห์

### 2.4 Gene Sequence (Constellation)
- ได้ตัวละครซ้ำ → ได้ "อัลลีล" 1 ชิ้น → ปลด 1 ลำดับ
- ตัวละครซ้ำหลัง C6 → แปลงเป็น "ผลึกดาวพันธุกรรม" ใช้แลกในร้าน

## 5. Gene Wish (ระบบสุ่ม / Gacha) — ⚠️ ไม่มีเงินจริง

### 5.1 สกุลเงิน
| ไอเทม | ได้จาก |
|------|-------|
| **ผลึกปัญญา (Insight Crystal)** | เควส, หีบ, Achievement, **ตอบ Quiz ถูก**, Daily Research, Evolution Tower |
| **เมล็ดพันธุกรรม (Gene Seed)** | แลกด้วยผลึกปัญญา 160 ต่อ 1 ใบ |
| **ผลึกดาวพันธุกรรม** | ได้จากการสุ่ม ใช้แลกในร้าน |

### 5.2 ตู้สุ่ม
| ตู้ | เนื้อหา | หมายเหตุ |
|----|--------|---------|
| **ตู้มือใหม่ (Novice Wish)** | 20 ครั้ง การันตี ★5 ตัวแรก (ฮีม่า) | ลด 20% |
| **ตู้ถาวร (Standard Gene Pool)** | ★5: ฮีม่า, เฮลิกซ์ | |
| **ตู้แบนเนอร์ตัวละคร (Featured)** | ★5 ตัวเด่น (เริ่ม: นิวรอส) + ★4 เด่น 3 ตัว | หมุนเวียนตามแพตช์ |
| **ตู้อาวุธ** | อาวุธซิกเนเจอร์ | เฟสหลัง |

### 5.3 อัตราและ Pity (ทำให้ใจดีกว่าเกมต้นแบบ)
| ค่า | ค่าที่ใช้ |
|----|--------|
| อัตรา ★5 พื้นฐาน | 1.2% |
| Soft pity | เริ่มที่ครั้งที่ 50 (+8%/ครั้ง) |
| Hard pity ★5 | **60 ครั้ง** |
| ★4 การันตี | ทุก 10 ครั้ง |
| 50/50 | หลุดตัวเด่นครั้งนี้ → ครั้งหน้าการันตีตัวเด่น |

### 5.4 ⭐ จุดเรียนรู้: "ห้องแล็บความน่าจะเป็น"
- หน้าสุ่มมีปุ่ม **"ทำไมถึงเป็นอัตรานี้?"** เปิดบทเรียนสั้น ความน่าจะเป็นแบบ Mendel (Punnett Square) และเทียบกับการสุ่ม
- แอนิเมชันสุ่ม = **"การปฏิสนธิ"**: อสุจิ/ไข่ล้อเป็นลูกแสง 2 ลูกรวมกัน — ★3 ฟ้า, ★4 ม่วง, ★5 ทอง (ออกแบบเป็นสัญลักษณ์ ไม่โจ่งแจ้ง) หรือทางเลือก: "เกลียว DNA หมุนแล้วแตกเป็นแสง"
- **Teacher Dashboard ปิดระบบ Gacha ได้** → ตัวละครทุกตัวปลดล็อกผ่านเควสแทน

| **ระดับน้ำ Osmosis** | วางก้อน "เกลือ/น้ำตาล" ในช่องเพื่อให้น้ำเคลื่อนข้ามเยื่อไปยกแพลตฟอร์ม | Osmosis / Hypertonic–Hypotonic |

| **เรียงระยะไมโทซิส** | กดเสาตามลำดับ Prophase → Metaphase → Anaphase → Telophase | การแบ่งเซลล์ |
| **กล้องจุลทรรศน์ยักษ์** | ปรับเลนส์ (ปรับหยาบ/ละเอียด) ให้ภาพชัดเพื่อหาทางลับ | การใช้กล้องจุลทรรศน์ |
| **วิธีการทางวิทยาศาสตร์** | สังเกต → ตั้งสมมติฐาน → ทดลอง (เลือกตัวแปรต้น/ควบคุม) → สรุป | การศึกษาชีววิทยา |

### 7.4 กลางวัน/กลางคืน และสภาพอากาศ

### 11.2 ⭐ ปฏิกิริยาสังเคราะห์ = บทเรียน
