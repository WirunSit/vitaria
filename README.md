# VITARIA: ตำนานธาตุแห่งชีวิต
### (Vitaria: Legends of the Vital Elements)

> เกม Open-World Action RPG สไตล์อนิเมะ (แนวเดียวกับ Genshin Impact) สำหรับเรียนรู้ **ชีววิทยา ม.4 – ม.6**
> ตามหลักสูตรแกนกลางฯ (ฉบับปรับปรุง 2560) รายวิชาชีววิทยาเพิ่มเติม ของ สสวท.

---

## แนวคิดในหนึ่งประโยค
ผู้เล่นคือ **"นักเดินทางแห่งชีวิต"** ที่ต้องท่องโลก **วิทาเรีย** ซึ่งแบ่งเป็น 7 ดินแดนตาม 7 ธาตุ — แต่ละดินแดนคือ "บทเรียนชีววิทยา" หนึ่งหมวด
ทุกสกิล ทุกปฏิกิริยาธาตุ ทุกศัตรู ทุกไอเทม ล้วนอ้างอิง **แนวคิดชีววิทยาจริง** และจะปลดล็อกสารานุกรม + แบบทดสอบเมื่อผู้เล่นพบเจอ

## หลักการออกแบบ 5 ข้อ (Design Pillars)
1. **"เล่นแล้วรู้ ไม่ใช่รู้แล้วค่อยเล่น"** – ความรู้ถูกฝังในกลไก (เช่น ยาปฏิชีวนะใช้ไม่ได้กับไวรัส) ไม่ใช่แค่ป๊อปอัปข้อความ
2. **ความถูกต้องทางวิชาการ** – ทุกเนื้อหาต้องผ่านการตรวจโดยครูชีววิทยา (มีช่อง `reviewed_by` ใน data)
3. **สนุกก่อน** – คุณภาพการต่อสู้และการสำรวจต้องสนุกแม้ไม่สนใจเนื้อหา
4. **ไม่มีการจ่ายเงินจริง** – Gacha ใช้สกุลเงินที่ได้จากการเล่น/เรียนเท่านั้น ครูปิดระบบ Gacha ได้
5. **ขยายได้เรื่อย ๆ** – ทุกระบบขับเคลื่อนด้วย Data (JSON/ScriptableObject) เพิ่มตัวละคร/เควส/ข้อสอบโดยไม่ต้องแก้โค้ด
